# Boss Con mèo - Detailed Spec

> Add the end-of-slice boss "Con mèo" to the vertical slice. After the 180-second survival timer, normal trash spawning stops and a big, placid-but-annoying cat appears; it wanders the room, sheds hairballs (Cục tóc rối) and periodically telegraphs a slap that knocks the robot back and drains battery. Killing the cat is now the win condition, replacing the pure timer win.

## Acceptance at a glance
- **AC-1** (MUST) - The boss "brain" shall be a pure, Unity-free state machine whose shed timing, enrage threshold and telegraphed-slap timing are unit-testable in EditMode.
- **AC-2** (MUST) - When placed in the scene, the boss shall wander to random points (pausing 2s on arrival), shed a Cục tóc rối on the shed interval, land a telegraphed slap on a nearby player, take damage like other trash, and NOT be knocked back or recycled when far.
- **AC-3** (MUST) - When the survival timer elapses, the system shall enter a boss phase: stop spawning new trash, spawn the boss once, and win only when the boss dies.
- **AC-4** (SHOULD) - While the boss is alive, the HUD shall show a boss health bar labelled "CON MÈO" that tracks the boss's health and hides when the boss dies.
- **AC-5** (MUST) - The editor build (`VSBuild`) shall create the boss EnemyData, prefab and sprite, wire the boss prefab into the spawner, and add the boss health bar to the HUD canvas, so the built scene shows the boss.

## Scope
- **In:** BossCat brain + behaviour, EnemyBase far-recycle guard, boss-phase win flow, boss HP bar, placeholder cat sprite, VSBuild wiring, EditMode tests for the brain.
- **Out:** Boss Máy hút bụi cũ; the 3-level structure; boss-specific music; camera shake / particles / hit-numbers polish; real art.

## Requirements & design notes

The boss reuses `EnemyBase` (health, white damage-flash, contact damage, `IDamageable` so `SuctionWeapon` already hits it, dust-on-death). Only `Move()` and `Die()` are overridden, plus two small hooks.

- **EnemyBase change (minimal, necessary):** add `protected virtual bool RecycleWhenFar => true;` and wrap the existing >30-unit teleport-toward-player block in `if (RecycleWhenFar && …)`. Existing enemies keep today's behaviour; the boss overrides it to `false` so it can roam the whole room.
- **No knockback on the boss:** set the prefab's `knockback` field to `0` in the Inspector (no code change) - `EnemyBase.TakeDamage` already multiplies by it.
- **Pure kernel pattern:** follow the existing codebase convention (`SliceClock`, `WaveSchedule`, `SplitLogic`, `SuctionStats`) - all decision/timer logic lives in a pure class under the `VacuumSurvivor` runtime asmdef, tested by `VacuumSurvivor.Tests.EditMode`. Vector2/Random movement stays in the MonoBehaviour.
- **Boss phase is still `State.Playing`:** so the robot, weapons and alive trash keep running. `GameManager` just flips a one-shot `bossPhase` flag at the survival deadline and raises `GameEvents.BossPhase` instead of calling `Win()`. `SliceClock.IsCleared` is reused unchanged (it now means "survival time reached → boss appears"); its tests stay green.
- **Demo:** `GameManager.SliceDuration` is already Inspector-tunable - lowering it jumps straight to the boss, so no cheat code is needed.
- **Telegraph:** during the 0.7s slap wind-up the boss sprite is tinted `telegraphColor` (a warm red); on the frame the wind-up ends the slap lands only if the player is still within `slapRange`. The brief white damage-flash may be overwritten by the telegraph tint during wind-up - acceptable, the boss HP bar carries hit feedback.
- **Slap effect:** knock the player's Rigidbody2D back `slapKnockback` units (impulse away from the boss) and apply `slapDamage` battery via `PlayerStats.TakeContactDamage`.
- **Boss is not pooled:** it is instantiated directly by the spawner on the boss phase, so `BossCat.Die()` fires the dust drop (`EnemyDied`) and calls `GameManager.Instance.Win()` rather than returning to a pool.

- **Global constraints:**
  - Namespace `VacuumSurvivor`; runtime asmdef `VacuumSurvivor`, tests asmdef `VacuumSurvivor.Tests.EditMode`.
  - Vietnamese UI uses legacy `UnityEngine.UI.Text` + `Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")` (renders diacritics). Boss label copy: exactly `CON MÈO`.
  - Boss stats (GDD Màn 1): maxHealth `400`, moveSpeed `2.0`, dustValue `40`. Slap: range `3`, knockback `6`, battery damage `15`, wind-up `0.7`s, cooldown `6`s. Shed: `3`s normal / `2`s enraged. Enrage: hp fraction `< 0.3`, speed multiplier `1.5`.
  - New enemies/pickups go on the `Enemy` layer with a collider so `SuctionWeapon` and contact damage work.

## Tasks

### AC-1 · Boss brain (pure kernel)
- [x] **T1** [M] `BossCatBrain` pure state machine + tests
  - files: `Assets/Scripts/Enemies/BossCatBrain.cs`, `Assets/Tests/EditMode/BossCatBrainTests.cs`
  - contract:
    `public enum Phase { Roaming, SlapWindup }`
    `public struct Decision { public bool Shed; public bool Telegraphing; public bool SlapHit; public bool Enraged; public float SpeedMult; }`
    ctor params (all with GDD defaults): `shedInterval=3, enragedShedInterval=2, slapCooldown=6, slapRange=3, windup=0.7f, enrageFraction=0.3f, enragedSpeedMult=1.5f`; `Phase Current { get; }`
    `Decision Tick(float dt, float distToPlayer, float hpFraction)` — `Enraged = hpFraction < enrageFraction`; `SpeedMult = Enraged?enragedSpeedMult:1`; shed timer uses interval `Enraged?enragedShedInterval:shedInterval`, emits `Shed` and subtracts the interval; in Roaming the slap timer advances and, once `>=slapCooldown && distToPlayer<=slapRange`, enters SlapWindup (resetting slap timer); in SlapWindup `Telegraphing=true` and after `windup` seconds emits `SlapHit = distToPlayer<=slapRange` and returns to Roaming.
  - tests: `sheds on the shed interval` · `enraged below thirty percent shortens shed interval and speeds up` · `does not enter windup when player out of range` · `enters windup then hits after the windup delay` · `slap misses when player leaves range during windup` · `does not slap again until cooldown elapses`
  - done when: `unity command run_tests -- --mode EditMode --timeout 120000` green (BossCatBrain cases pass, suite stays green)
